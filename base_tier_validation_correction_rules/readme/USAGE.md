To use this module:

- As a user with the Tier Review Correction role:
- Open any document (e.g., a Purchase Order) that has already started the validation process.
- In the yellow banner (pending state), click on the "Change Reviewer" link on its right side.
  - A wizard will pop up showing the original approver and the new approver.
  - Select the new approver.
  - It will automatically create a document tier correction and update the reviewer.
