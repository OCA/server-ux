To configure Tier Reviewer Rules:

1. Go to **Settings > Technical > Tier Validations > Tier Review Correction Rules**.
2. Create a new record.
3. Select the **Referenced Model** for which you want to apply the rule.
4. In the **Reviewer Rule** tab, add lines to define permissions:
   - **User**: Select the user who will be performing the reviewer change.
   - **Allowed Reviewers**: Select the users that this specific User is allowed to select as new approvers.

**NOTE**
If no rule is defined for a user on a specific model, they will be able to select any user as the new reviewer.
