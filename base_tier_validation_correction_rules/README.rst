This module add rules reviewer on change reviewer

- **Enhanced User Experience**: The correction wizard now clearly
  displays both the original approver and the proposed new approver,
  improving the user experience during reviewer changes.
- **Reviewer Change Rules**: A new configuration "Tier Review Correction
  Rules" allows defining specific rules for changing reviewers, enabling
  restricted or guided selection of new approvers.

Configuration
=============

To configure Tier Reviewer Rules:

1. Go to **Settings > Technical > Tier Validations > Tier Review
   Correction Rules**.
2. Create a new record.
3. Select the **Referenced Model** for which you want to apply the rule.
4. In the **Reviewer Rule** tab, add lines to define permissions:

   - **User**: Select the user who will be performing the reviewer
     change.
   - **Allowed Reviewers**: Select the users that this specific User is
     allowed to select as new approvers.

**NOTE** If no rule is defined for a user on a specific model, they will
be able to select any user as the new reviewer.

Usage
=====

To use this module:

- As a user with the Tier Review Correction role:
- Open any document (e.g., a Purchase Order) that has already started
  the validation process.
- In the yellow banner (pending state), click on the "Change Reviewer"
  link on its right side.

  - A wizard will pop up showing the original approver and the new
    approver.
  - Select the new approver.
  - It will automatically create a document tier correction and update
    the reviewer.
