This module allows to set filters as default for all the users, consequently sharing the filter with everyone.

**Table of contents**

.. contents::
   :local:

Usage
=====

To use this functionality you need to select, in any view, Favorites > Save current search > Select both, "Use by default" and "Share with all users".
