To use this module, you need to:

1.  Go to **Settings > Technical > Automation > Automated Actions**.
2.  Create a new Automated Action or select an existing one.
3.  Set the **Action To Do** (state) to `Add Followers`.
4.  In the **Add Sales Teams as Followers** field, select one or more Sales Teams.
5.  (Optional) You can still add individual partners in the standard **Add Followers** field. The module will combine both lists.
6.  Save the action.

**Example result:**
When the trigger conditions are met (e.g., a new Opportunity is created), Odoo will look up all members currently assigned to the selected Sales Teams and add their associated Partners as followers to the record chatter.
