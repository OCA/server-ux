**BUSINESS NEED**

In Odoo, Automated Actions (base_automation) allow users to automatically add followers to a record. However, in the standard version, you must select specific individual Partners one by one.

In many organizations, notification requirements are team-based.

Managing these subscriptions individually is tedious and error-prone. If a new member joins a Sales Team, an administrator would have to manually update every single Automated Action to include that new user.

**APPROACH**

This module extends the "Add Followers" action type within Automated Actions to include a "Add Sales Teams as Followers" field.
