This module extends the functionality of automated actions to allow to
"Add Followers" all members of a sales team.

Use Cases / Context
===================

**BUSINESS NEED**

In Odoo, Automated Actions (base_automation) allow users to
automatically add followers to a record. However, in the standard
version, you must select specific individual Partners one by one.

In many organizations, notification requirements are team-based.

Managing these subscriptions individually is tedious and error-prone. If
a new member joins a Sales Team, an administrator would have to manually
update every single Automated Action to include that new user.

**APPROACH**

This module extends the "Add Followers" action type within Automated
Actions to include a "Add Sales Teams as Followers" field.

Usage
=====

To use this module, you need to:

1. Go to **Settings > Technical > Automation > Automated Actions**.
2. Create a new Automated Action or select an existing one.
3. Set the **Action To Do** (state) to ``Add Followers``.
4. In the **Add Sales Teams as Followers** field, select one or more
   Sales Teams.
5. (Optional) You can still add individual partners in the standard
   **Add Followers** field. The module will combine both lists.
6. Save the action.

**Example result:** When the trigger conditions are met (e.g., a new
Opportunity is created), Odoo will look up all members currently
assigned to the selected Sales Teams and add their associated Partners
as followers to the record chatter.
